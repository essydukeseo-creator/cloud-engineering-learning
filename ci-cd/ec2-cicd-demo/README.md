# EC2 CI/CD Demo

## Project Overview

This project demonstrates how to automate the deployment of a simple website to an AWS EC2 instance using GitHub Actions.

## Tools and Technologies

- AWS EC2
- Git and GitHub
- GitHub Actions
- Linux
- HTML
- AWS IAM
- OpenID Connect (OIDC)

## Project Structure

- `index.html` – The website being deployed.
- `.github/workflows/deploy.yml` – GitHub Actions deployment workflow (stored at the repository root).

## Project Goal

To understand how Continuous Integration and Continuous Deployment (CI/CD) work by automating application deployment to an AWS EC2 instance.

## Learning Outcomes

- Understanding CI/CD pipelines.
- Using GitHub Actions for automation.
- Connecting GitHub Actions to AWS using OIDC.
- Deploying a website to an EC2 instance.
