# Amazon EC2

EC2 provides virtual servers in AWS.

## Things I Learned

- EC2 instances are virtual servers.
- AMIs are used to launch EC2 instances.
- Security groups control inbound and outbound traffic.
# AWS IAM

IAM manages access to AWS resources.

## Things I Learned

- IAM controls who can access AWS resources.
- Users can be given specific permissions.
- IAM policies define what actions are allowed or denied.
# Amazon VPC

VPC allows you to create a private network in AWS.

## Things I Learned

- VPCs provide isolated networks in AWS.
- Subnets divide a VPC into smaller networks.
- Route tables control how network traffic is routed.
# Amazon S3

S3 is an object storage service in AWS.

## Things I Learned

- S3 stores objects such as files and documents.
- Data is stored inside buckets.
- S3 can be used for backups and static website files.
# Git Basics

Git is a version control system.

## Things I Learned

- Git tracks changes made to files.
- Commits save changes to the Git history.
- Git allows developers to work with different branches.
# Git Collaboration

Git makes it easier for developers to work together.

## Things I Learned

- GitHub hosts Git repositories online.
- `git pull` downloads changes from a remote repository.
- `git push` uploads local commits to a remote repository.
