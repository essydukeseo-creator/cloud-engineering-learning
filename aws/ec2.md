# Amazon EC2

EC2 provides virtual servers in AWS.

## Things I Learned

- EC2 instances are virtual servers.
- AMIs are used to launch EC2 instances.
- Security groups control inbound and outbound traffic.

## More About EC2

EC2 instances can be placed in public or private subnets.

Security groups act as virtual firewalls.

EC2 instances can use IAM roles to access AWS services.
